# Product Requirements Document

Product: MedMemory

Version: 1.0

## Problem

Medical records are difficult to manage.

Most records are:

- Paper based
- Scattered
- Difficult to search
- Easy to lose

Patients and caregivers need a simple way to organize medical history.

## Goal

Create a secure digital health vault.

## User Persona

### Persona 1

Adult child managing healthcare for parents.

Pain Points:

- Records are everywhere
- Hard to track medications
- Difficult to explain history to new doctors

### Persona 2

Patient managing chronic illness.

Pain Points:

- Many reports
- Multiple doctors
- Frequent hospital visits

## User Stories

### User Registration

As a user,
I want to create an account,
so that I can securely manage records.

### Patient Profile

As a user,
I want to create patient profiles,
so that I can organize family records separately.

### Upload Documents

As a user,
I want to upload medical reports,
so that they are securely stored.

### AI Extraction

As a user,
I want important information extracted automatically,
so that I do not need to enter data manually.

### Timeline

As a user,
I want a chronological view of medical history,
so that I can understand health events quickly.

### Search

As a user,
I want to search medical history,
so that I can find records instantly.
